Limitations

  • Calibration lags 2–3 months (the label needs 60 days): ECE rises when the monthly churn rate moves. Ranking unaffected.
  • Deposit features unused while the data lacks completed deposits before March 2026.
  • Source recency and tenure columns broken: recomputed from activity.
  • One model per brand: retrain and check before scoring another brand.
