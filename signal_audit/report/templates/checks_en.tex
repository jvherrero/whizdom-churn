\section{Evaluation Criteria}
Each column has its checks in the catalogue. The row checks (formula and limit) run on every row of the snapshots; the \emph{recomputed} ones apply the workbook rule with its inputs recomputed from the daily gaming and payments tables, player by player, on day $D$ and on days $D+1$ to $D+10$: a correct column matches on $D$; if it matches better later, it uses data from the future. Each input is computed with the days of any wallet and with the official active days (M053), and the one that matches best is given. A check \emph{passes} if it holds in at least 99\%. Tolerance: $0.01 + 0.001\,|f|$.
